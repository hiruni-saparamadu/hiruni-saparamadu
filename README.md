## 📌 Featured Projects

### 🌬️ Smart Breeze — AI + IoT Air Conditioning System

An intelligent air conditioning solution that combines machine learning, IoT, and computer vision to optimize energy efficiency and comfort.

- Developed automatic temperature adjustment and occupancy-based airflow.
- Implemented adaptive air conditioning control and humidity regulation.
- Co-authored research on the system, published through IEEE ICTIR 2024.

**Tech Stack:** Python, Machine Learning, IoT, Computer Vision

### ⚡ Carbon Footprint Prediction System

A time-series forecasting pipeline to predict air conditioning energy consumption and estimate CO₂ emissions using weather and sensor data.

- Engineered temporal and autoregressive features from 10,000+ records.
- Evaluated Random Forest, XGBoost, LightGBM, LSTM, and GRU models.
- Implemented rolling-window forecasting and TimeSeriesSplit cross-validation.

**Tech Stack:** Python, Pandas, NumPy, Scikit-learn, XGBoost, LightGBM, TensorFlow

### 🖼️ AI Image Quality Enhancer

An AI-powered image enhancement pipeline for low-quality photographs and scanned documents.

- Integrated Real-ESRGAN for image super-resolution.
- Integrated GFPGAN for face restoration.
- Developed adaptive image analysis for blur, brightness, document types, and facial features.
- Implemented multi-stage enhancement and high-resolution PDF page processing.

**Tech Stack:** Python, Computer Vision, Real-ESRGAN, GFPGAN, Image Processing

### 🧠 AI-Driven POS Design & Code Generation Pipeline

A Python-orchestrated engineering pipeline that transforms functional requirements and Figma designs into Android POS applications.

- Automated Java/XML screen implementation and Android design-system generation.
- Integrated Figma API workflows for component synchronization and screen generation.
- Developed Python validation for generated specifications, UI states, navigation, and code.
- Built and tested Android applications using Gradle and ADB on physical POS terminals.

**Tech Stack:** Python, Java, XML, Android, Figma API, Gradle, Git

### 🩺 Diabetes Prediction System

A machine learning application that predicts diabetes risk using a Support Vector Machine (SVM) and provides an interactive interface for predictions.

**Tech Stack:** Python, Scikit-learn, SVM, Streamlit

### 🎬 Movie Recommendation System
